# Eiffel Tower Asset

Local asset used for the Eiffel Tower rocket animation.

- Import path used by the script: `assets/eifel_tower/eifel_munarasy.glb`
- Original local companion files not tracked here: `Eifel_Munarasy.usdz`,
  `eifel_munarasy.zip`, `eifel-munarasy.zip`
- Source URL: not yet recorded
- License: not yet recorded

The generated Blender scene scales this tower uniformly to match the imported
rocket bounding-box height, then parents it to the animated rocket rig while
keeping the existing smoke and fire simulation setup unchanged.
